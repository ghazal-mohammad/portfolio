Overview

DT.Teeth is a dental clinic management system that brings the administration, secretary, doctor, warehouse, lab and patient interfaces together across web and mobile. I built the Flutter Web application for the Warehouse and Lab Manager roles and integrated it with the team's Laravel 11 backend.

What I built

  • The Warehouse and Lab Manager modules in Flutter Web
  • Full dark and light theme support, RTL-first Arabic/English localization and responsive layouts
  • A custom authentication flow: splash, email entry, OTP verification and password setup
  • A reusable shared widget library used across the app
  • Integration with the Laravel 11 REST backend, and real-time push notifications with Firebase Cloud Messaging

Architecture

Clean Architecture with BLoC for state, GoRouter for navigation, GetIt for dependency injection, Dio for networking and Freezed for immutable models.
